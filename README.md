# 📦 Parcel Management System - Java

A console-based **Parcel Management System** built using **Core Java**. This application allows users to manage parcel records through a simple menu-driven interface.

---

## 📖 Description

The Parcel Management System is a beginner-friendly Java project demonstrating Object-Oriented Programming (OOP) concepts and CRUD operations. Users can add, search, update, view, and delete parcel records without using a database.

---

## ✨ Features

- Add Parcel
- View All Parcels
- Search Parcel by ID
- Update Parcel Details
- Delete Parcel
- Parcel Status Management
- Menu-Driven Interface

---

## 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class

---

## ▶️ How to Compile

```bash
javac ParcelManagementSystem.java
```

---

## ▶️ How to Run

```bash
java ParcelManagementSystem
```
